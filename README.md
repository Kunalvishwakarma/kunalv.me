# kunalv.me — Professional Portfolio

Personal portfolio website for Kunal Vishwakarma, an enterprise IT infrastructure professional based in Norway.

**Live website:** https://kunalv.me  
**GitHub profile:** https://github.com/Kunalvishwakarma  
**Technical portfolio:** https://github.com/Kunalvishwakarma?tab=repositories

## Overview

The site presents professional experience and selected independent technical work across:

- Enterprise infrastructure and infrastructure architecture
- Datacenter migration, transformation and decommissioning
- Microsoft Azure and hybrid-cloud environments
- Enterprise networking and infrastructure security
- OT cybersecurity concepts and technical project delivery

## Website features

- Responsive, dark-themed portfolio interface
- English and Norwegian language views
- Project, experience, skills, credentials and case-study sections
- Downloadable CV workflow
- Interactive profile Q&A panel
- Technical portfolio links to five public GitHub repositories
- SEO and social-sharing metadata

## Technology

- HTML, CSS and JavaScript
- Tailwind CSS
- Lucide icons
- GitHub repository hosting / Pages-compatible static site structure

## Publication and security notes

- Keep personal contact details, credentials, API secrets and private information out of source control.
- Treat any browser-side form identifier as public; enforce spam controls and validate submissions server-side where applicable.
- Review CV files, screenshots and case studies before public distribution.
- Technical portfolio examples are independent learning material, conceptual designs or synthetic scenarios unless explicitly identified as validated implementations.
- Do not publish customer or employer confidential information or imply employer endorsement.

## Local preview

Open `index.html` in a browser, or serve this directory with any simple static HTTP server. External libraries and fonts are loaded from their respective CDNs.
